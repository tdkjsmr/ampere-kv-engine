# v0.1 状态与云端验收

## v0.1 目标

v0.1 只完成后续引擎开发所需的 G0/G1 地基，不实现完整推理引擎。

当前源码包含：

- Qwen3-8B 固定 Revision、元数据哈希和 Shape 契约；
- BF16/INT8 候选 KV Cache 容量计算；
- 运行环境 JSON Schema 与去身份化采集脚本；
- 面向 sm_86 的最小 CUDA Extension；
- 覆盖尾部 Mask 的最小 Triton Kernel；
- CPU/GPU 分层测试与 HF Reference 采集入口；
- 不包含自然语言 Prompt 的仓库安全边界。
